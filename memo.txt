## ■ Undo / Redo（完成状態）

### 【操作】

* Ctrl + Z：Undo
* Ctrl + Y：Redo
* Ctrl + Shift + Z：Redo

---

### 【履歴対象】

* ペン
* 直線
* 矢印
* 長方形
* 消しゴム
* テキスト追加 / 編集 / 移動
* Clear

---

### 【履歴仕様】

* 1操作 = 1履歴
* プレビューは履歴に含めない
* 矢印は複数Strokeでも1履歴
* Eraseは1ドラッグ = 1履歴
* Clearは1履歴
* 履歴上限あり（200）

---

## ■ 進行中操作 × Undo / Redo / Clear

### 【基本ルール】

① 進行中操作を処理
② Undo / Redo / Clear 実行

---

### 【未確定操作】

→ キャンセル

対象：

* ペン描画中
* 直線 / 矢印プレビュー
* 長方形プレビュー
* テキスト編集中
* テキスト移動中

---

### 【確定扱い】

→ 1履歴として確定してからUndo

対象：

* Erase（削除済みのため）

---

### 【意図】

* 今の操作はなかったことにして戻る
* ただし削除はUndoで戻す

---

## ■ Clear仕様

* 描画 + テキストを全削除
* 1履歴として管理
* Undoで復元可能

---

## ■ 内部構造

### 【状態管理】

```csharp
enum InteractionState
{
    None,
    DrawingPen,
    DrawingLine,
    DrawingArrow,
    DrawingRect,
    Erasing,
    EditingText,
    MovingText
}
```

---

### 【Undo管理】

* UndoHistoryManager を使用
* Stack操作はManagerに集約
* 履歴上限もManagerで管理

---

### 【Action設計】

* IUndoableAction ベース
* 操作ごとにActionクラス作成
* PushHistoryで登録

---

### 【共通処理】

```csharp
void FinalizeOrCancelCurrentOperation()
{
    switch (CurrentState)
    {
        case DrawingPen:
        case DrawingLine:
        case DrawingArrow:
        case DrawingRect:
        case EditingText:
        case MovingText:
            CancelCurrentOperation();
            break;

        case Erasing:
            CommitEraseOperation();
            break;
    }

    CurrentState = None;
}
```

---

## ■ 実装ルール（超重要）

1. 新機能は必ずUndo対応込みで実装する
2. 1操作 = 1履歴を守る
3. プレビューは履歴に入れない
4. Undo/Redo/Clear前に状態整理
5. 未確定はキャンセル、変更済みは確定
6. 履歴は PushHistory 経由のみ
7. Stackを直接触らない
