FlowInk

FlowInkはWindows画面のアノテーション(落書き)ツールです
Windows画面へ説明、メモ書きを、シンプルに行えます。

ダウンロード

ZIPファイルをダウンロードして、解凍して起動してください。

特長

余計な操作を増やさず、必要な機能をすぐ使えることを重視した設計です。

オーバーレイ描画

デスクトップ画面の上にそのまま書き込めるので、説明や確認が直感的です。

シンプル操作

最小構成のUIで、迷いにくく、起動してすぐ使い始められます。

テキスト入力

線や図形だけでなく、補足説明やラベルもその場で追加できます。

軽量設計

重たいセットアップなしで、必要なときにすぐ立ち上げて使えます。

こんな用途に

ちょっと書き込みたい場面に、手早く使えるツールです。

画面説明

会話しながら見せたい場所に線や文字をすばやく追加。

作業メモ

一時的な書き込みや補足メモを画面上に残せます。

チャートへの書き込み

デイトレード等のチャート画面にラインや矢印などを記入

使い方

導入はシンプルです。

1. 配布ZIPをダウンロード
2. 解凍して FlowInk を起動
3. そのまま画面上に描画・入力

FlowInkを試す

必要なときにすぐ起動して、画面上にすぐ書ける。
まずはダウンロードして、使い心地を試してみてください。
