FlowInk

Windows画面に直接描ける
軽量なオーバーレイ描画・落書きツール

ダウンロード

インストーラーをダウンロードして実行するとインストールできます。実行時にPC保護の警告が出る場合は「詳細情報」ボタンを押して実行してください。※無名なソフトなのでマイクロソフトから警告されてしまいます。

プレゼンやチャートなど、さまざまな画面にその場で書き込めます。

特長

余計な操作を増やさず、必要な機能をすぐ使えることを重視した設計です。

オーバーレイ描画

デスクトップ画面の上にそのまま書き込めるので、説明や確認が直感的です。

シンプル操作

最小構成のUIで、迷いにくく、起動してすぐ使い始められます。

テキスト入力

線や図形だけでなく、補足説明やラベルもその場で追加できます。

軽量設計

重たいセットアップなしで、必要なときにすぐ立ち上げて使えます。

ツールバーの各ボタンの説明

ツールバーの各ボタンをクリックしたときの機能をまとめています。

描画ON/OFFボタン

描画ON/OFFの切り替えができます。クリックすると背後のウィンドウを操作できるようにします。描画OFFにするとツールバーは畳まれます。Ctrl+Alt+Tキーを同時に押す事と同じ機能です。

ペンボタン

マウスの左ボタンを押してドラッグすると線を描画できます。Shiftキーを押しながらドラッグすると直線、Shift+Altキーで矢印を描画できます。ペンボタンにカーソルを合わせてマウスの右ボタンをクリックすると線幅のプリセットポップアップが開いて線幅を変更できます。また、プリセットの線をダブルクリックするとプリセットの線幅を変更できます。

四角形ボタン

マウスの左ボタンをクリックしてドラッグすると四角形を描画できます。四角形ボタンにカーソルを当てて右クリックすると塗りつぶし／塗りつぶす色の透明度を変更できます。

円ボタン

マウスの左ボタンをクリックしてドラッグすると円を描画できます。円ボタンにカーソルを当てて右クリックすると塗りつぶし／塗りつぶす色の透明度を変更できます。

テキストボタン

キーボードからテキストが入力できます。Enterで文字列確定、Shift+Enterでテキストボックス内で改行できます。テキストボタンをダブルクリックするとフォントを変更できます。入力したテキストをクリックするとテキスト選択状態となり、ドラッグするとテキストを移動できます。また、テキスト選択状態でテキストにカーソルを当てて右クリックするとテキストの編集／削除ができます。

消しゴムボタン

マウスの左ボタンを押しっぱなしにすることで、描いた線／円／四角をカーソルで消せます。ただしテキストは消せません。

カラーボタン

描画色を変更できます。マウスの左ボタンをクリックすると、色選択ポップアップが開きます。選択することで描画色を変更できます。Preset Colorsの各色タイルをダブルクリックすることでプリセットの色を変更できます。また、色ボタンをダブルクリックすると現在の色を変更できます。

クリアボタン

画面上に描いた内容をすべて消去します。テキストも消去されます。

設定ボタン

描画ON/OFFができるグローバルホットキーを設定できます。デフォルトはCtrl+Alt+Tです。

終了ボタン

FlowInkを終了します。

その他の機能

ツールバーボタン以外の機能です。

  • Ctrl + alt + T で描画ON/OFFを切り替えられます。設定ボタンでキーの組み合わせを変更できます。
  • Ctrl-Z / Ctrl-yでUndo / Redoができます。履歴は200です。
  • テキスト入力時にEnterで文字列確定。Shifet+Enterで改行できます。
  • テキスト入力時に Ctrl + マウスホイールの上下で文字サイズを拡大・縮小できます。
  • ペンボタン選択時、Shiftキーで直線、Shift + Altキーで矢印を描画できます。
  • ツールバーの余白をつかむと移動できます。(余白にカーソルを合わせて左ボタンクリックでドラッグ)

こんな用途に

ちょっと書き込みたい場面に、手早く使えるツールです。

プレゼン／オンライン会議

表示／共有している画面に直接直接書き込みできます。

作業メモ

一時的な書き込みや補足メモを画面上に残せます。

チャートへの書き込み

デイトレード等のチャート画面にラインや矢印などを記入できます。

インストール方法

インストーラーを実行します。

1. FlowInk-Setup.exeをダウンロード
2. FlowInk-Setup.exeを実行 「Windows によってPCが保護されました」の警告が出る場合は「詳細情報」ボタンを押して実行してください。※無名なソフトなのでマイクロソフトから警告されてしまいます。
3. 画面に従ってインストール

FlowInkを試す
