FlowInk

FlowInkはWindows画面のアノテーション(落書き)ツールです
Windows画面へ説明、メモ書きを、シンプルに行えます。

ダウンロード

ZIPファイルをダウンロードして、解凍して起動してください。

特長

余計な操作を増やさず、必要な機能をすぐ使えることを重視した設計です。

オーバーレイ描画

デスクトップ画面の上にそのまま書き込めるので、説明や確認が直感的です。

シンプル操作

最小構成のUIで、迷いにくく、起動してすぐ使い始められます。

テキスト入力

線や図形だけでなく、補足説明やラベルもその場で追加できます。

軽量設計

重たいセットアップなしで、必要なときにすぐ立ち上げて使えます。

ツールバーの各ボタンの説明

ツールバーから、描画・編集・表示切替をすばやく行えます。

ペン

自由に線を描画できます。注釈や手書きメモをすばやく入れたいときに使います。

四角形

四角形を描画して、範囲や注目箇所を囲めます。

円

円や楕円を描画して、ポイントを丸く強調できます。

テキスト

説明文や補足メモを画面上に直接入力できます。

消しゴム

描いた内容を部分的に消したいときに使います。

カラー

描画色を変更できます。用途に応じて色分けしたいときに便利です。

クリア

画面上に描いた内容をまとめて消去します。

クリック透過 / CT

描画を表示したまま、背後のウィンドウを操作できるようにします。

設定

動作や表示に関する設定を開きます。

終了

FlowInkを終了します。

こんな用途に

ちょっと書き込みたい場面に、手早く使えるツールです。

画面説明

会話しながら見せたい場所に線や文字をすばやく追加。

作業メモ

一時的な書き込みや補足メモを画面上に残せます。

チャートへの書き込み

デイトレード等のチャート画面にラインや矢印などを記入

使い方

導入はシンプルです。

1. 配布ZIPをダウンロード
2. 解凍して FlowInk を起動
3. そのまま画面上に描画・入力

FlowInkを試す

必要なときにすぐ起動して、画面上にすぐ書ける。
まずはダウンロードして、使い心地を試してみてください。
